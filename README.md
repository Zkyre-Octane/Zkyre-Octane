### 🚀 About Me

I’m a cybersecurity &amp; embedded systems enthusiast with hands-on experience in ESP32 firmware development, open-source projects, and custom hardware prototyping. My work bridges the gap between hardware and software, focusing on building modular, secure, and maintainable embedded systems.

🔭 &nbsp;I'm currently working on **RavenOS - An open source option for ESP32-driven tools**  
🌱 &nbsp;I'm currently learning **low-level systems: binaries, inodes, and file structures**  
🤔 &nbsp;I'm looking for help with **RavenOS**  
⚡ &nbsp;Fun fact: **the first RavenOS device was an ESP32 attached to a breadboard**
